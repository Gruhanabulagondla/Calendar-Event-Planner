# Calendar Event Planner 📅

A Python-based Calendar Event Planner for managing events and calculating the number of days remaining until each event.

## Features

- Add events
- Store event dates
- View all events
- Sort events by date
- Calculate days remaining
- Identify completed events
- Identify today's events

## Technologies Used

- Python
- datetime
- Lists
- Dictionaries
- Functions

## How to Run

```bash
python calendar_event_planner.py
